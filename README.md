# How the States Stack Up – Victoria in focus

A single-page, evidence-based comparison of Australia's states and territories on debt, tax, jobs, housing, services, safety, energy and integrity, with Victoria in focus ahead of the 28 November 2026 state election.

**Live page:** https://briank1080.github.io/government_performance/ (once GitHub Pages is enabled)

## What's here

| File | Purpose |
|---|---|
| `index.html` | The whole web page: self-contained HTML, CSS and JavaScript, no build step |
| `README.md` | This file |

## How to update

1. Edit `index.html` (or ask Claude to; see `Project_Instructions.md` in the Claude Project).
2. Upload or commit it to the `main` branch.
3. GitHub Pages republishes automatically within a minute or two.

## Enabling GitHub Pages

1. Go to **Settings → Pages**.
2. Under **Source**, choose "Deploy from a branch".
3. Select branch `main`, folder `/ (root)`, then **Save**.

## Data and sources

- Figures come from 2026-27 budget papers, Auditor-General reports, the ABS, AIHW, the Productivity Commission, energy regulators and AAP reporting. Every source is listed at the bottom of the page.
- Estimates and mixed measures are labelled on the page.
- The page is analysis, not financial advice, and does not recommend how to vote.
